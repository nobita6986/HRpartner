# Repository Agent Entry Point

Canonical instructions live in `.ai-pipeline/`.

Before work, read:

1. `.ai-pipeline/README.md`
2. `.ai-pipeline/rules/00-global-rules.md`
3. Exactly one role file: `.ai-pipeline/tier0.md`, `tier1.md`, `tier2.md`, or `tier3.md`
4. The current work artifact

Skill selection is documented in `.ai-pipeline/skills/README.md`. Do not load every skill and do not assume another role without explicit assignment.
