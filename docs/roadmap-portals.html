Nền tảng Design System & Public Layout WIP

Exit: Giao diện public có khung chuẩn, sẵn sàng ráp component.
M2
Landing Page & Chợ Việc Làm TODO
Cắt HTML từ stitch/hrp_landing_page_html_standard. Tích hợp API /api/jobs vào thanh tìm kiếm. Xây dựng luồng Apply hồ sơ.
Exit: Ứng viên tự do có thể tìm việc và nộp hồ sơ chuẩn SEO.
M3
Affiliate / CTV Workspace TODO
Biến ctv.hrpartner.vn thành Marketing & Sales Hub. Tích hợp mã Referral QR, biểu đồ hoa hồng realtime.
Exit: CTV có công cụ xịn để kiếm tiền và rải link.
M4
Worker Workspace & Kiến trúc Chịu tải TODO
Giải bài toán Thundering Herd vào kỳ lương. Pre-compute Payslip từ Python, Redis Cache, Neon Connection Pooling, Rate Limiting.
Exit: App Công nhân mượt mà, chịu tải 10,000 req/s.
M5
BoD Dashboard & Vendor Workspace TODO
Dashboard tổng hợp cho Giám đốc (Headcount, Quỹ lương). Quản lý Pipeline và Đối soát công nợ cho Vendor.
Exit: Toàn bộ hệ sinh thái HRP khép kín hoàn chỉnh.
