C-04 — Fail-closed delegation detector
=========================================

Round: 2 (v1.2)

Change:
-------
File: `src/domains/applications/marketplace-inventory.static.test.ts`

Removed hard-coded `ADMIN_GUARDED_VIA_HELPER` allowlist (which v1.1 used
to enumerate specific route file names). Replaced with dynamic
fail-closed checks:

  guardedViaPlacementHelper(routeSource):
    1. route imports `runPlacementCommand` (static AST/regex check)
    2. route CALLS `runPlacementCommand` (not just imports it)
    Both conditions required — `import` alone does NOT count.

  placementHelperHasSecurityMarkers(helperSource):
    1. helper contains `getAuthContext`
    2. helper contains `withDbContext`
    Both required.

Negative fixture (new file): `tests/security/admin-route-fail-closed.negative-fixture.ts`
  - declares `export async function POST`
  - does NOT import placement.route-helpers
  - does NOT call `runPlacementCommand`
  - does NOT contain `getAuthContext` or `withDbContext`
  - proves detector flags unguarded mutating routes
