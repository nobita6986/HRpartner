## 1. Outcome

### 1.1 User-visible outcome (post-implementation, target)

1. **HR_MANAGER (or ADMIN) classifies ServiceModel**: trên trang `/admin/job-openings/[id]`, khi JobOpening còn `DRAFT` và caller là `ADMIN`/`HR_MANAGER`, panel "ServiceModel" hiển thị 4 enum (`STAFFING_SUPPLY`/`LABOR_LEASING`/`RECRUITMENT_SERVICE`/`REFERRAL_SERVICE`). Caller chọn một giá trị → POST `/api/admin/staffing/job-openings/[id]/classify` với JSON body `{ serviceModel: chọn-một-trong-bốn-enum-trên }` (chú thích trong ngoặc chỉ là typographical note; actual HTTP body là JSON `{"serviceModel":"STAFFING_SUPPLY"}` chẳng hạn) và `Idempotency-Key` UUID v4 → nếu hợp lệ: 200 + `router.refresh()` → chip ServiceModel hiện trên page. **`null`, missing, hoặc enum không thuộc 4 value → 400 `INVALID_INPUT` (Zod)**. HR_STAFF **không** thấy controls (server-rendered role gate). JobOpening đã `OPEN`/`FILLED`/`CANCELLED` hoặc đã có `Placement` → controls bị disable (server-rendered) + API từ chối 409 `INVALID_STATE_TRANSITION`. Typed error class: `JobOpeningActivationError` (analog carryover của `AdminApplicationError` / `ApplicationServiceError` / `RecruiterAssignmentError`); KHÔNG dùng `PlacementValidationError` cho JobOpening activation.
