## 1. Outcome

### 1.1 User-visible outcome

Closes the regression T0 surfaced against F9-B round 1: after this round, an assigned `HR_STAFF` writer still gets the round-1 least-privilege write path (no broad `SELECT ... FOR UPDATE` on `staffing_order_slots`; binding via the SECURITY DEFINER primitive `hrp_f9b_bind_slot_to_opening`; the round-1 narrow INSERT/UPDATE manager policies retained; no DELETE policy; no broad column-agnostic mutation), AND every other legitimate read role resumes canonical read access to slots of projects they should see:

- **MKT** sees slots of `is_public = true` projects (canonical for public JobPosting / job-board surface).
- **CTV** sees slots of `is_public = true` projects (canonical for CTV public job-board / referral surface).
- **PM** sees slots of their own projects (canonical for Demand Tree).
- **DIRECTOR**, **SALE**, **WORKER**, **VENDOR_ADMIN**, **VENDOR_STAFF** see slots of projects they can already see at the project-scope (canonical).
- **HR_STAFF** sees slots of orders they have an ACTIVE `StaffingOrderRecruiterAssignment` on (existing narrow `hrp_sora_order_slots_staff_select` preserved).
- **HR_MANAGER** and **ADMIN** see slots of all projects (existing broader `hrp_f9b_slots_manager_*` policies preserved; they keep the manager SELECT path).
- **unassigned/revoked HR_STAFF** does NOT see slots of orders they are not assigned to (zero-row fail-closed, no leakage).
- **HR_STAFF direct UPDATE** on slots still fails closed (B-01 preserved).
- **HR_STAFF INSERT** on slots still fails closed (no INSERT policy for HR_STAFF on this table).
- **HR_STAFF DELETE** on slots still fails closed (no DELETE policy introduced).
- **PUBLIC cannot EXECUTE** the binding primitive (B-02 preserved).

`publicSelect` (MKT) for JobPosting card returns the public cards; `Demand Tree` (PM) returns the projects they own; the F9-B round-1 binding primitive still mutates only `staffing_order_slots.job_opening_id`; the F9 narrow INSERT/UPDATE policies on `job_openings` / `job_postings` remain intact.
