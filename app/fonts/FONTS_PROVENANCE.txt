#       1. curl the seven files above from raw.githubusercontent.com/google/fonts

#   The byte sizes are pinned to the upstream google/fonts `size` field; the
#   github-API `sha` field is the git blob SHA (over the compressed git object),
#   NOT a hash of the raw file bytes, so we use size + sha256 instead.
